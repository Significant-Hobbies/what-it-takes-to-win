## Why

The product explains survivor bias and luck accurately, but visitors must assemble the emotional conclusion themselves. The homepage needs one memorable, evidence-bounded visual that makes a famous outcome feel like the visible end of a branching sequence rather than a reasonable benchmark.

## What Changes

- Add a signature homepage narrative showing many plausible starts narrowing through repeated uncertain gates to one visible peak.
- Use a clearly labelled 64-to-1 coin-toss thought experiment to make repeated selection intuitive without presenting it as dataset evidence.
- Explain that starting advantage can change the odds, built leverage can improve later odds, runway can create more attempts, and luck still affects individual outcomes.
- Add the emotional turn in plain language: visitors are comparing an unfinished branch with a publicly visible surviving streak.
- Replace the generic homepage ending with a grounded agency statement about inspecting the next controllable branch.
- Extend automated clarity checks to protect the illustration and its non-empirical boundary.

## Capabilities

### New Capabilities

- `survivor-path-narrative`: A visually memorable, emotionally resonant explanation of repeated uncertainty, survivor selection, and comparison release.

### Modified Capabilities

- `luck-and-variance`: Luck is explained as repeated exposure across consequential gates, not only as a list of categories.
- `outcome-model`: The homepage’s first-time explanation includes the survivor-path framing, and the comprehension count is aligned with the six-question contract.

## Impact

- Updates the homepage structure and global responsive styling.
- Updates the clarity audit, product status, and existing outcome/luck specifications.
- Uses semantic HTML and CSS only; no new dependency, runtime script, data field, backend, or infrastructure change is required.
