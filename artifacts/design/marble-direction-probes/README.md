# Marble-race direction review

Temporary, non-production comparison surface for the reopened overhaul gate.
All three probes use the same thesis, evidence count, reading contract, primary
navigation, and essay pair so the review compares systems rather than content.

- `marble-theatre.html` — cinematic 3D world with a quiet editorial reading room
- `counterfactual-broadcast.html` — chapter-led explanatory broadcast
- `kinetic-essay.html` — annotated research essay with the course drawn into the page

The probes are absent from production navigation, analytics, indexing, and the
normal visitor journey. No direction is approved until the owner selects one.
